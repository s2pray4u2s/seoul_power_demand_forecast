# 🔋 기상 기반 전력 수요 예측을 통해 피크 대응 및 운영 최적화 전략 구현

> Data Analytics Bootcamp 2026 · 팀 프로젝트
> 서울시 전력사용량 · 기상청 · 에어코리아 공공데이터 기반 (2023~2024, 17,544시간)

2025년 여름 104.1GW, 2026년 한파 88.9GW — 역대 최고 수요 경신이 이어지는 상황에서,
기상 변동성을 통제 가능한 데이터로 변환해 **설비 제어 및 탄소 저감까지 연결된 전력 수요 예측 시스템**을 구축했습니다.

## 💡 Key Findings — 4대 구조적 변동성

단순 기온 비례가 아닌 복합 기상 및 캘린더 변수에 따른 부하 격차 실증

| 구분 | 수치 |
|------|------|
| 냉방 민감도 | 기온 1°C 상승 시 **+277.3 MWh** (난방의 5.4배) |
| 난방 민감도 | 기온 1°C 하락 시 **+51.8 MWh** |
| 공휴일 감소 | 평일 대비 **-13.3%** (5,347 → 4,636 MWh) |
| 폭염일 급증 | 일반일 대비 **+53.3%** (5,080 → 7,790 MWh) |

**계절별 피크 시각**

| 계절 | 피크 시각 | 피크 수요 |
|------|-----------|-----------|
| 봄 | 12시 | 5,365 MWh |
| 여름 | 15시 | 7,776 MWh |
| 가을 | 18시 | 6,097 MWh |
| 겨울 | 11시 | 6,813 MWh |
